# Drone2
Another drone , with modified frame, customized motor drivers 

WHAT CHANGED:
1. Custom motor drivers using MOSFETs and diode for preventing reverse current. Rated for 5A max output current.
2. 3D printed custom mini drone frame from bamboo Lab, which i didnt recorded as it was not under permit. Nor saved the file.
3. All hardware integrated into perfboard for better connectivity and durability.

Same on-ground remote control from main project.
